# Adaptive Filters — SUT (Fall 2025)

* **Overview:** Official repository for assignments, projects, and computational implementations of the M.Sc. Adaptive Filters course at Sharif University of Technology (Fall 2025).
* **Core Topics:** Analysis and implementation of adaptive filtering algorithms including LMS, NLMS, RLS, and spectral estimation.
* **Projects & Code:** MATLAB simulations for noise cancellation, echo suppression, and channel estimation alongside convergence analysis.
* **Prerequisites:** Advanced Digital Signal Processing (ADSP), Stochastic Processes, and Applied Linear Algebra.
